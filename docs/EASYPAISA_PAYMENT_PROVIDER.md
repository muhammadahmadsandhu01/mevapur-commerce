# Easypaisa Payment Provider

Status: installed source adapter, dormant, disabled by default, not externally activated.

P2.2 does not invent endpoints, signing rules, result codes, callbacks or sandbox behavior. The adapter reports `PAYMENT_PROVIDER_NOT_CONFIGURED`, exposes no public checkout method and contains no fake success response.

Activation requires official merchant onboarding, official current API documentation, sandbox credentials, signing/callback verification tests and controlled external verification.
