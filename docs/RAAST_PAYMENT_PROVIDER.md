# Raast Payment Provider

Scope: manual Pakistan Raast transfer, PKR only.

Availability requires an approved public account title and public Raast ID. The customer receives bounded instructions, submits a transaction reference, and waits in `AwaitingVerification`.

Only an authorized admin may approve or reject. Customer submission cannot self-complete a payment. Automated Raast API behavior is deliberately not implemented because no verified official integration contract was supplied.
